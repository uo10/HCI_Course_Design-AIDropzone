# 标签显示与窗口置顶修复计划

## Bug 1：中文标签显示为 `__`

**根因**：`FileDetailPanel.addTag` 将非 `a-z0-9_` 字符全部替换为 `_`，中文被抹掉。

**修复**：`normalizeUserTag` 与后端 `Tag` 一致——允许中英文，仅去掉空白与 `<>:"/\|?*` 等非法字符；长度 1–64。

**改动**：`src/utils/normalizeUserTag.ts`、`FileDetailPanel.tsx`、`后端接口一览.md` §0.3。

## Bug 2：主面板始终置顶

**根因**：`electron/main.ts` 创建窗口时 `alwaysOnTop: true`，展开面板后未关闭。

**修复**：

| 模式 | alwaysOnTop |
|------|-------------|
| panel（主面板） | false |
| ball（悬浮球） | true |

**改动**：`applyPanelMode` / `applyBallMode` / `createWindow` 初值。
